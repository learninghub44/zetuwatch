Good to know

Questions, answered.

What does ZetuWatch monitor?

The initial product is focused on HTTP and HTTPS websites and API endpoints. SSL expiry, cron heartbeats, DNS and TCP checks are planned as later capabilities.

Do I need a credit card to start?

The planned Free tier does not require a payment method. You can begin with a small set of monitors and upgrade only when you need more capacity.

How quickly will I know a site is down?

Detection depends on the configured check interval and incident confirmation policy. The actual interval and delivery performance will be shown transparently; no detection time is guaranteed before the service is production-ready.

Can I share service health with customers?

Public status pages are part of the product roadmap. You will be able to publish selected components and incident updates once that feature is available.

Is ZetuWatch production-ready today?

The project is under active development. This site describes the intended product; account creation, monitoring, notifications and billing must be completed and verified before customer use.
