# Product roadmap

## Phase 0 — foundation
- [x] Public repository and project documentation
- [x] Initial D1 schema
- [x] Worker API health endpoint
- [x] Conservative HTTP probe foundation
- [ ] CI checks and automated tests

## Phase 1 — usable monitoring
- [ ] Authentication and account isolation
- [ ] Create, edit, pause and delete HTTP monitors
- [ ] Scheduled checks with per-monitor intervals
- [ ] Persist check history and response time
- [ ] Incident confirmation and recovery rules
- [ ] Email notifications

## Phase 2 — customer product
- [ ] Customer dashboard and onboarding
- [ ] Public status pages
- [ ] Cron heartbeat monitors
- [ ] SSL expiry checks
- [ ] Usage limits and plan enforcement

## Phase 3 — revenue
- [ ] Paid plans and billing integration
- [ ] M-Pesa/card checkout where supported
- [ ] Receipts, renewals and failed-payment handling
- [ ] SMS credits and paid usage add-ons

## Phase 4 — scale
- [ ] Multi-region probes
- [ ] Dedicated worker/queue infrastructure
- [ ] Team roles, audit exports and SSO
- [ ] Retention tiers and service-level reporting

A feature is not complete until it is tested, documented, secured and observable.
