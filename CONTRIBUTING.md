# Contributing

1. Open an issue describing the bug or proposal before large changes.
2. Keep changes small and focused.
3. Add tests for validation, scheduling and incident logic.
4. Never commit credentials, customer data or production configuration.
5. Document schema changes as forward-only migrations.
6. Run `npm run typecheck` before submitting a pull request.

By submitting a contribution, you agree that it is provided under the repository's Apache-2.0 license unless a separate written agreement applies.
